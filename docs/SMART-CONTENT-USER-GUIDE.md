# Guía rápida — Content Autopilot

1. Abre `@HomesteadServicesNotifyBot`.
2. Envía `/publicar` y las fotos del trabajo (o un álbum).
3. Opcional: una nota corta de lo que hiciste.
4. Toca **Procesar**.
5. El bot te muestra copy, hora recomendada (Panamá) y botones.
6. **Aprobar horario** deja la pieza programada. **Publicar ahora** simula la salida mientras DRY RUN esté activo.
7. Consulta `/pendientes`, `/programadas`, `/proxima`, `/publicadas`.
8. `/pausa` detiene el scheduler.

Mientras no haya tokens de Instagram/Facebook, **nada se publica en redes**. El contenido queda guardado en Homestead.
